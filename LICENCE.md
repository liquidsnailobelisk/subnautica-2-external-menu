## 🧩 About

**Subnautica 2 desktop helper** is a curated list of Subnautica 2 open-source tools:

- **Overlays** — on-screen helpers, layout notes, depth readout, biome markers
- **Quality-of-Life Helpers** — inventory notes, recipe catalog, crafting reference
- **Research Notes** — base layout plans and config notes for educational use

Based on publicly available community tools and overlay helpers.

---

## ✨ Features

### 🎮 Exploration Helpers
- Depth Readout — on-screen depth and pressure reference
- Biome Markers — note points of interest while exploring
- Compass Notes — heading reference for surface and cave routes
- Speed Notes — playback reference for traversal study

### 🎒 Inventory & Crafting
- Recipe Catalog — browse craftables and ingredient lists
- Inventory Notes — organize gathered materials
- Storage Tracker — keep a manual log of base storage

### 🏗️ Base Layout
- Base Planner Notes — sketch room layouts and connections
- Power Reference — compare generator and battery options
- Vehicle Notes — organize upgrade and module checklists
